How the matching sheets work

Each worksheet has two columns with the same number of boxes. The left column lists kana in order, and the right column lists their partners shuffled. The student draws a line from each box on the left to its match on the right. The black dots between the columns mark where each line starts and ends.

The right column is always rearranged so that no item sits directly across from its partner. The student can't just draw straight lines, and has to read each character.

Choosing what to match

  • Hiragana ↔ Katakana: connect the two characters that stand for the same sound. It suits learners who know hiragana and find katakana harder to remember.
  • Hiragana ↔ Romaji, Katakana ↔ Romaji: practice reading kana. The rarely used ぢ and づ are shown as "di" and "du" so they stay distinct from じ and ず.
  • Number of choices: how many boxes each column has, up to 20. Start with one row (5 boxes) and raise the number for a harder sheet. Bigger sheets use smaller boxes so they still fit on one page.
  • Rows plus random kana: the kana from the rows you tick are always used. Tick only the ア行 and set the number to 15, for example, and you get those 5 kana plus 10 random ones. If the number is smaller than the rows' kana, that many are picked from them at random. Tick no rows and every kana is random. Regular kana (%) sets the mix of basic kana and dakuten/handakuten kana among the random ones.
  • Trick choices: boxes with no partner, added to both columns in equal numbers (they count toward the number of choices). When a student finds one, they circle it and write that kana in its other form beside it, for example hiragana as katakana. Every worksheet carries this instruction, whether or not it has trick choices, so students can't tell. The answer key marks trick choices with an X and shows the answer.

Tips for using the sheets

  • Read before drawing. Have the student read the left column aloud before drawing any line.
  • Watch for look-alikes. Shapes such as シ and ツ, or ソ and ン, make good practice when they share a set.
  • Follow up with writing. Once matching feels easy, move on to the Kana Conversion Quiz, where the student writes the answer.

Frequently asked questions

Is there an answer key?

Yes. With "Include answer key page" on, the PDF ends with the same page again, with every correct line drawn in. Trick choices are marked with an X and the correct form is written beside them. The worksheet can also carry a QR code (on by default) that opens a plain list of the answers on a phone; untick "Add an answer QR code" to leave it off.

How is this different from the Kana Conversion Quiz?

Matching only needs lines, with no writing, so it suits younger children and first-time learners. The Kana Conversion Quiz asks the student to look at one script and write the other.

Why doesn't the PDF print 行 for each row?

The Japanese font embedded in the PDFs contains only the characters the worksheets use, and 行 isn't one of them, so the PDF doesn't print row names.
