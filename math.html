How to use the Math Worksheet Generator

  1. Pick a starting level. The six Quick Template buttons set every option at once. Start with the level that matches what your child is learning now. You can adjust anything afterward.
  2. Check the preview. The Problem Selection Preview shows a sample of the problems your settings will produce, so you can check the difficulty before you print.
  3. Set the layout. Rows and Cols set how many problems fit on a page. Fewer, larger problems suit younger children and vertical (column-form) arithmetic. More problems suit quick fact drills.
  4. Generate and print. You get one PDF with the worksheet pages followed by the answer-key pages. Print only the pages you need.

Teaching tips

Regrouping (carrying and borrowing)

Regrouping is where many children first get stuck with multi-digit arithmetic. Start with Allow regrouping turned off, so every column can be solved on its own, and turn on Vertical form so digits line up by place value. When those sheets feel easy, turn regrouping on. Seeing both kinds of problems on one sheet helps a child learn to check each column before starting.

Short, frequent practice

A sheet of 8 to 20 problems a day usually does more than one long sheet a week. Since every sheet is new, children can't memorize the answers. They have to actually work each problem.

Missing-number problems for reasoning

The Cryptarithms % setting hides one number in a problem, for example 7 + ☐ = 12, and the child works out what's missing. It makes a child think about how addition and subtraction (or multiplication and division) undo each other, which is the start of algebraic thinking. Mix in a few at 10 to 20% to break up a routine sheet.

Frequently asked questions

How do I check answers quickly?

Every PDF includes answer-key pages. With Add Answer-key QR code turned on, each worksheet page also gets a QR code. Scan it with a phone camera to see that page's answers without finding the printout.

What is the code at the top of each page?

It's a worksheet-matching code. The same code is printed on the worksheet and on its answer-key page, so you can match a stack of finished sheets to the right keys. The code includes the date, so sheets printed on different days never share a code.

Can I save my settings?

Yes. Export (.ini) saves your current settings to a small file. Import it later to make the same kind of sheet again, with new problems.

What does this tool not cover?

It focuses on arithmetic, expressions, and simple equations. It doesn't make fractions, geometry, money, or word problems.
