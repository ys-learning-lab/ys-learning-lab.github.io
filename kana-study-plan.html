A Step-by-Step Plan for Learning Hiragana and Katakana

Study Plan Kana Chart Kana Conversion Quiz Kana Matching Writing Practice Word Builder Online Learning

This plan uses the Japanese tools on this site in order. Writing practice introduces each letter, a weekly matching sheet reviews the finished rows, and quizzes check what has stuck. A few minutes a day is enough. The key rule: every letter a student misses, in writing or out loud, comes back in the next test until it is truly memorized.

The plan at a glance

  1. Hiragana, one new letter a day with Writing Practice.
  2. A matching sheet once a week for every row (行) finished so far.
  3. Katakana, the same way, once all hiragana are done.
  4. Conversion quizzes in order: hiragana to katakana first, then katakana to hiragana.
  5. A randomized quiz every day. Missed letters get extra writing practice and go into the next quiz, again and again, until they are memorized. On a busy day, a quick round of Tap Practice can stand in for the quiz.

All the way through: the student points at letters and says them out loud. Any letter they can't say goes back into the quiz too.

Step 1: One new hiragana a day

Open Writing Practice, choose Hiragana and Single character(s), and pick today's letter from the list. The sheet shows a model of the letter and one faint copy to trace, then leaves the rest of the boxes empty so the student writes it alone. The default of 15 repetitions fills one page.

  • Follow the rows. Go through あ行 (あいうえお), か行, さ行 and so on, ending with わ行 (わ, を, ん). At one letter a day, five days a week, you finish about one row a week and all 46 hiragana in about ten weeks.
  • Put up the chart. Print the hiragana chart and keep it where the student practices, so each new letter has its place among the ones already learned.
  • Show the stroke order first. The sheets don't print stroke-order arrows, so show the order from a textbook or another trusted reference before the student starts tracing.
  • At least one letter a day. Daily practice matters more than speed. If the earlier letters are solid, two letters a day is fine. If they aren't, slow down.
  • Add a word when you can. Turn on Also practice writing an example word so the letter is written inside a real word, not only on its own.

Step 2: A matching sheet for each finished row

At the end of each week, make a Kana Matching sheet. Set Match to Hiragana ↔ Romaji and tick every row the student has finished so far, not only this week's row, so older letters keep getting reviewed. The student draws a line from each letter to its reading.

  • Number of choices: each column holds up to 20 boxes. Once the ticked rows have more letters than that, the tool picks from them at random, so every new sheet tests a different mix.
  • Trick choices: after a few weeks, turn on Add trick choices that match nothing. The student has to read every box instead of guessing the last few by elimination.
  • Note every mistake. Turn on the answer key to check the sheet. Any letter matched wrongly goes on the student's missed-letter list (see Step 6).

Step 3: Katakana, the same way

When all 46 hiragana are done, repeat Steps 1 and 2 with katakana: choose Katakana in Writing Practice, and Katakana ↔ Romaji in Kana Matching. Katakana has no built-in example words, so type your own (for example a short word the student already knows) if you want a word row. Toward the end, a Hiragana ↔ Katakana matching sheet is a good bridge to the quizzes. Use the katakana chart the same way as the hiragana one.

Step 4: Conversion quizzes in order

Once both scripts have been covered, start the Kana Conversion Quiz. Here the student sees a letter in one script and writes it in the other, from memory. Press the Basic Hiragana ⇆ Katakana template:

  1. First press: hiragana to katakana, in row order. The familiar あいうえお order helps on the first pass.
  2. Second press: katakana to hiragana, in row order.

Repeat each one until the student can finish it with only a few mistakes.

Step 5: A randomized quiz every day

Press the same template a third and fourth time for randomized sheets, first hiragana to katakana, then katakana to hiragana. Without the row order to lean on, the quiz shows whether each letter is really known. Once both directions feel easy, keep only Basic ticked and choose Mixed (anti-cheat) under Direction, so one sheet asks for both scripts.

Aim for a short quiz every day rather than a long one once a week. Lowering Rows gives a smaller sheet, for example 4 rows of 5 letters.

No time for a quiz? Use Tap Practice

On a busy day, a round of Tap Practice can take the place of the printed quiz. It runs on a phone, tablet or computer with no printing: one letter is shown, and the student taps its match from a few choices. Ten or twenty questions take only a few minutes.

  • Set it up like the quiz. For example, set Question to Katakana and Choices to Hiragana, tick the rows the student has learned, choose the Number of questions, and press Start.
  • Use it while learning, too. During Steps 1 to 3, a quick round with Question set to Hiragana (or Katakana) and Choices set to Romaji is an easy review of the finished rows between weekly matching sheets.
  • Missed letters still count. The results list every answer. Press Practice missed only for another round of just those, use Make a writing practice sheet to print a tracing sheet of them, and add them to the missed-letter list for the next printed quiz (Step 6).
  • Keep writing in the week. Tapping checks that a letter is recognized, not that it can be written from memory. Use Tap Practice to fill a gap, and return to the Kana Conversion Quiz on days when there is time.

Why writing stays on paper

Stroke order is an important part of learning Japanese letters. But the accuracy of writing on a phone, tablet or with a mouse is nowhere near that of pencil and paper: small boxes are hard to fit a letter into, and a finger or mouse cannot make the same strokes. So this site does not teach stroke order on screen.

Instead, the plan puts the two jobs where they work best. Writing is done on paper, with Writing Practice sheets and repetition. Recognition is done on screen, with quick rounds of Tap Practice. What matters most is that the student practices a little every day.

Step 6: Practice the missed letters, then test them again

This loop is what turns "mostly known" into "memorized". After every quiz:

  1. Practice right away. Make a Writing Practice sheet for each missed letter, or have the student write it several times on the back of the quiz paper.
  2. Put it in the next quiz. Type the missed letters into Always include before making the next quiz. Romaji works too, for example nu, me, ne, so you don't need a Japanese keyboard.
  3. Keep it there until it sticks. Leave a letter on the list until the student gets it right on several quizzes in a row, then take it off.

For a class: the quiz's Class roster (Excel) option makes one test per student. Download the template, write each student's name and missed letters, import it, and every student's test includes their own missed letters.

Say it out loud: the reading check

Writing a letter from memory and reading it on sight are different skills. A student who writes a letter correctly on a quiz can still pause when they meet it in a word. So, alongside every step above, check reading too.

  • Point and say. Point at letters on a finished sheet or on the charts (with romaji hidden), in a random order, and have the student say each one out loud.
  • Missed means missed. Any letter the student can't say, says wrongly or has to think hard about goes on the missed-letter list, exactly like a quiz mistake. It gets written practice and goes into the next quiz.
  • Little and often. A minute or two at the end of each day's practice is enough.

Hiragana and katakana charts

The Kana Chart page has both charts in the traditional order. Print them to keep beside the desk, and for the point-and-say check set Sub 1 and Sub 2 to None so only the main letters show.

A sample week

Day 7 Rest, or catch up on any letter that is still shaky Rest, or a quick point-and-say review

After the basics

When the 46 basic letters of both scripts are solid, add the other categories in the Kana Conversion Quiz one at a time: dakuten (が), then handakuten (ぱ), then youon (きゃ). Use the same missed-letter loop for each. Writing Practice covers only the basic letters, so practice missed letters from these categories on the back of the quiz paper.

Frequently asked questions

How long does the whole plan take?

At one letter a day, five days a week, each script takes about ten weeks, so both take around five months before daily quizzing starts. The daily quiz stage has no fixed end: keep going until the missed-letter list stays empty.

Does this work for older learners?

Yes. Adjust the settings and the pace to each learner.
