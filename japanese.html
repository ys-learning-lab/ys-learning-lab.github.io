    What this worksheet practices

    Japanese uses two phonetic scripts that stand for the same sounds. Hiragana (ひらがな) is used for native words and grammar. Katakana (カタカナ) is used mostly for words borrowed from other languages. Every sound has one character in each script, for example あ and ア for "a". This worksheet shows a character in one script, and the student writes the matching character in the other.

    Converting in both directions builds a stronger link between the two scripts than reading either one on its own. Many learners pick up hiragana first and then find katakana hard to remember, and this drill targets that gap.

    The kana categories

    • Basic: the 46 core characters, from あいうえお through ん.
    • Dakuten (゛): two small marks that voice a sound, for example か (ka) becomes が (ga) and さ (sa) becomes ざ (za).
    • Handakuten (゜): a small circle that turns the は row into the p sounds, for example は (ha) becomes ぱ (pa).
    • Youon: combined sounds written with a small ゃ, ゅ, or ょ, for example き + ゃ = きゃ (kya).

    A common order is: basic hiragana, then basic katakana, then dakuten and handakuten, then youon. Add a category only when the previous one feels easy.

    How to use the templates

    Each Quick Template button changes its setup every time you press it again:

    1. In order, grouped by row (H→K): characters appear in the familiar あいうえお, かきくけこ order. This is best for a first pass, when the pattern of each row helps memory.
    2. In order, the other direction (K→H).
    3. Randomized (H→K): the same characters, shuffled. The student can no longer rely on row order, which shows whether each character is really known.
    4. Randomized, the other direction (K→H).

    All Types Mixed (Anti-Cheat) mixes both directions on one page, so some boxes ask for hiragana and others ask for katakana. The student has to read every prompt carefully instead of filling in one script automatically.

    How the anti-cheat setting works: the risk with a mixed sheet is that one box gives away another. Suppose one box shows ショ and asks for hiragana, while another box shows し and asks for katakana. The first prompt already contains the answer (シ) to the second. To prevent this, the generator groups related kana into families by their base sound: し, じ, シ, ジ, シャ, ショ and the other sa-row sounds are all one family, as are the ka row with が and キャ, and so on. A whole family always goes the same direction on a sheet, so a prompt in one script never shows the answer to a related box. In Mixed mode each family is given a random direction, which gives you hiragana and katakana prompts on one sheet without these giveaways. The same rule applies to the characters you list under Always include. The Katakana→Hiragana ratio is the share of boxes that should ask for hiragana. Because whole families are assigned together, the result is close to that ratio, not exact.

    Frequently asked questions

    Do I need a Japanese keyboard?

    No. All settings are buttons and checkboxes, and the student writes the answers by hand on paper.

    How do I check the answers?

    The PDF ends with answer-key pages. Each box on the worksheet has a small number, and the answer key and the answer-key QR code list answers in the same order: left to right, top to bottom.

    Can a random layout spell something inappropriate?

    The generator checks every randomized grid for a short list of inappropriate words, read across or down. If it finds one, it moves the characters before the sheet is made.

    Can I go back to a sheet I made earlier?

    Yes. The Recent generations list keeps the settings of your last five worksheets in this browser. Choose one to load its settings again.
