How the practice sheets work

Each character gets its own column of large square boxes. The top box shows a model of the character. The first box below it has the same character in faint gray to trace over. The rest are empty, so the child writes it without help. This model, then trace, then write-alone pattern is how handwriting is taught in Japanese schools.

Columns read from top to bottom and fill the page from right to left, the way Japanese is traditionally written. Each box has faint crosshair guide lines that divide it into four quarters. They help a child place and balance each stroke.

Choosing what to practice

  • Single character: for a character that's giving your child trouble. It defaults to 15 repetitions, which fills a page. You can also add an example word that uses the character, so the child practices it in a real word.
  • By row (行): hiragana are grouped into rows of up to five sharing a consonant, such as あ行 (あいうえお) and か行 (かきくけこ). Practicing one row at a time follows the order most learners and textbooks use.
  • All 46 basic hiragana: a full review once every row has been introduced.

Tips for handwriting practice

  • Size matters early. Big boxes let young hands build the motion first. Precision comes later.
  • Watch the balance. Use the crosshairs to point out where strokes should start and end. あ and お, for example, differ mainly in how their parts are balanced.
  • Learn stroke order separately. These sheets don't show stroke-order arrows. Before tracing a new character, show your child its stroke order from a textbook or a trusted reference, then use these sheets for repetition.
  • A few minutes daily. One row per day, written slowly and carefully, builds better habits than a rushed page of the whole alphabet.

Frequently asked questions

Why doesn't every character have an example word?

Some characters, notably を and ん, almost never begin a word, so there's no natural example. Those characters skip the word row.

Does it cover katakana or voiced sounds like が?

This tool focuses on the 46 basic hiragana. For recognizing dakuten, handakuten, and youon, and for katakana, use the Kana Matching Quiz.

Is there an answer key?

No. There's nothing to grade on a tracing sheet. Compare your child's writing with the model character at the top of each column instead.
