How the puzzle sheet works

Each page is a small crossword. A list of kana is printed above the grid, and exactly those kana are needed to fill every empty box. The student writes one kana in each box so that every word reading across and every word reading down is a real hiragana word, and crosses each kana off the list as it is used.

The words come from the same everyday word list as the other Japanese tools. There are no clues, so the student works by trying kana in the boxes and checking the words they make. Some kana are already filled in to help.

Using the sheets

  • When to use it. After the student can read most of the hiragana. It is good practice for reading short words and for noticing which kana go together.
  • How many words. Start with 7 words and "Many" letters shown. For a bigger challenge, raise the words up to 15 and show "Few" letters.
  • Saving paper. Each puzzle fills one page with large boxes, so there is room to write neatly and nothing is wasted.
  • Prefer the screen? The Kana Word Puzzle in Online Learning is the same crossword, played by dragging kana.

Frequently asked questions

Is there an answer key?

Yes. With "Include answer key pages" on, the PDF ends with one key page for each puzzle, showing the grid filled in. Another set of real words that fills the grid is also correct, so the key is one good answer, not the only one.

Does it include katakana?

Not yet. The word list is hiragana only, so the puzzle is hiragana.

Is anything saved or sent?

No. The puzzles and the PDF are made in your browser, and nothing about them is stored or uploaded.
