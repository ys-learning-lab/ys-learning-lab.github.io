Quiz options

Questions come from the kana you ticked, each one before any repeats. If you ask for more questions than there are kana, the list goes around again.

For example, you tick only the ア行 (あいうえお). On: the wrong choices are the other kana from that row (い, う, え, お), so they look alike and it is harder. Off: wrong choices can be any kana (like ね or ぷ), so it is easier. If the ticked rows have too few kana, others fill in.

How tap practice works

Choose which characters are shown as the question and which are offered as choices, tick the rows of kana to practice, and press Start. Each question shows one character, and the student taps the choice that stands for the same sound. It works with a finger on a phone or tablet, and with a mouse or the number keys on a computer.

At the end you see the score and a list of every question with the student's answer and the correct one, so missed kana are easy to spot. Practice missed only starts a new round with just those.

Setup ideas

  • Hiragana to katakana: Question: Hiragana, Choices: Katakana. Good for a learner who knows hiragana and is building katakana.
  • Reading practice: Question: Hiragana, Choices: Romaji, to check that each character is read correctly.
  • Start small: tick one or two rows and use 3 choices. Add rows and choices as it gets easy.
  • Look-alike trap: Question: Katakana, Choices: Hiragana and Katakana. Hiragana and katakana are both among the choices, so the student can't pick by shape alone (only one choice is correct).

Learn by sound, then check the shape

A kana character is easier to remember when its sound and shape are practised together. Start by saying the sound before tapping a choice. If the learner needs help, turn on Sound and use the speaker for the question character, then listen once more after the answer. Later, try the same small set with Sound off. That makes it clear whether the character can be recognized from its shape alone or still needs a sound reminder.

Use the two script settings to change the kind of thinking the quiz asks for. Hiragana question with romaji choices checks reading. Hiragana question with katakana choices checks whether the learner can connect two written forms of the same sound. Mixing both scripts in the choices makes a learner slow down and listen rather than relying only on a familiar outline.

The score is the number correct out of the questions asked, not a permanent record. The useful part is the answer table: it shows the question, the selected answer, the correct answer, the time for that question, and whether Sound was used. Filter to missed answers, choose Practice missed only, or make a writing sheet from those characters. That turns one short round into a specific next practice step.

Keep a new round short enough that every answer can be discussed. When a choice is missed, compare the two characters side by side and say both sounds, then try that character again later instead of repeating it immediately. Increase the number of choices only when the current group can be answered without guessing. A mixed-script round is useful after that, because it checks the sound connection rather than a single familiar visual pattern.

Frequently asked questions

Are scores saved?

No. Everything happens in the browser and nothing is sent anywhere. Scores and answers stay on screen until you leave the page or start again. Only your setup (which kana, how many choices and so on) is remembered, in this browser, so you don't have to set it up each time.

Why is ぢ shown as "di" and づ as "du"?

So that each romaji choice has only one correct kana. The more common じ and ず use "ji" and "zu".
