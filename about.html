About Ys Learning Lab

Why this site exists

Ys Learning Lab started as a set of small programs written to make practice sheets for home learning. Printed workbooks run out, repeat the same problems, and rarely match what a child is working on this week. A generator doesn't have those limits. You describe the practice you want, and it makes a fresh sheet every time, with a matching answer key.

The original tools were desktop scripts. This site rebuilds them to run in any web browser, so any parent or teacher can use them without installing anything.

What you'll find here

  • Math Worksheet Generator: addition, subtraction, multiplication, and division, including regrouping, long division, decimals, negative numbers, multi-step expressions with parentheses, missing-number problems, and simultaneous equations. Six preset levels get you started in one click.
  • Japanese Kana Worksheet Generator: hiragana-to-katakana and katakana-to-hiragana conversion quizzes covering the basic kana, dakuten, handakuten, and youon combinations.
  • Hiragana Writing Practice: trace-and-copy handwriting sheets laid out in vertical columns that read right to left, the way Japanese is actually written.

How the worksheets are designed

  • Every sheet comes with an answer key. Answer-key pages are added to the same PDF, and each worksheet can carry a QR code that shows the answers on a phone.
  • Worksheet codes match sheets to keys. Each page is stamped with a short code, such as XRGD0831-A-1, that also appears on its answer-key page, so a stack of papers is easy to grade.
  • Built for paper. PDFs are plain black-on-white to save ink. QR codes sit away from where a child's hand rests while writing.
  • Private by design. Everything is generated inside your browser. Nothing you type is uploaded. See the Privacy Policy.

Free, supported by ads

The tools are free to use with no sign-up. Ads on the tool pages help cover the time spent building and improving them. Suggestions and bug reports are welcome on the Contact page.
