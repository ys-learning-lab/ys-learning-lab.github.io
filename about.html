About Ys Learning Lab

Why this site exists

Ys Learning Lab started as a set of small programs written to make practice sheets for home learning. Printed workbooks run out, repeat the same problems, and rarely match what a child is working on this week. A generator doesn't have those limits. You describe the practice you want, and it makes a fresh sheet every time, with a matching answer key.

The original tools were desktop scripts. This site rebuilds them to run in any web browser, so any parent or teacher can use them without installing anything.

What you'll find here

The Japanese section collects everything for learning hiragana and katakana:

  • Kana Study Plan: a step-by-step plan that says which tool to use each day, from one new letter a day to daily quizzes that bring back every missed letter.
  • Hiragana and Katakana Charts: the 46 basic letters in the traditional order, with a second and third reading (hiragana, katakana or romaji) shown small under each letter if you like. The chart can be printed on A4 or larger paper.
  • Kana Writing Practice: trace-and-copy handwriting sheets for hiragana or katakana, laid out in vertical columns that read right to left, the way Japanese is actually written.
  • Kana Matching Worksheet: draw-a-line sheets that connect hiragana, katakana and romaji, with optional trick choices and an answer key.
  • Kana Tap Practice: on-screen practice for a phone, tablet or computer. One letter is shown, the student taps the match, and the score and every answer appear at the end.
  • Kana Conversion Quiz: hiragana-to-katakana and katakana-to-hiragana quizzes covering the basic kana, dakuten, handakuten, and youon combinations, with an answer key.

For math, there is the Math Worksheet Generator: addition, subtraction, multiplication, and division, including regrouping, long division, decimals, negative numbers, multi-step expressions with parentheses, missing-number problems, and simultaneous equations. Six preset levels get you started in one click.

How the worksheets are designed

  • Answers are included where there is something to check. The math, quiz and matching worksheets add answer-key pages to the same PDF, and each can carry a QR code that shows the answers on a phone. The writing practice sheets have nothing to grade, so they have no answer key.
  • Worksheet codes match sheets to keys. Each answer-key worksheet page is stamped with a short code, such as XRGD0831-A-1, that also appears on its answer-key page, so a stack of papers is easy to grade.
  • Built for paper. PDFs are plain black-on-white to save ink. QR codes sit away from where a child's hand rests while writing. The tap practice runs on screen and needs no printer.
  • Private by design. Everything is generated inside your browser. Nothing you type is uploaded. See the Privacy Policy.

Free, supported by ads

The tools are free to use with no sign-up. Ads on the tool pages help cover the time spent building and improving them. Suggestions and bug reports are welcome on the Contact page. If the site has helped you, an optional tip on the Support page is another way to help.
