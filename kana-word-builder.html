Sheet options

Every sheet has two puzzles. Each puzzle has ten different kana and asks for four words, written in five boxes each. The two puzzles are matched so that neither has fewer words to find.

What will be generated

The kana of your worksheet. The PDF uses exactly these kana.

How the word sheets work

Each puzzle shows a row of hiragana. The student makes words from them, using each kana at most once in a word. Each word is written in its own column of square boxes, one letter to a box, from top to bottom, with the columns filling from the right, the way Japanese is written. A word scores one point for every letter, so はし is 2 points and はしら is 3. The points go in the small box under the word, and the student adds them all up at the bottom.

Every set of kana is built around a real 5-kana word from the site's word list, so there is always a long word to find. The two puzzles on a sheet are matched, so each one can make about the same number of words from the list, and the four best words are worth about the same. Each puzzle asks for four words, written in five boxes each, which fits the longest words in the list. Other real words count too, which is why the answer key shows examples rather than a complete list.

Using the sheets

  • When to use it. After the student knows a good part of the hiragana. The kana come from everyday words, so the sheets work best once most rows are learned.
  • About the points. Every letter is worth one point, so longer words win. Finding a long word is worth more than finding two short ones.
  • Prefer the screen? The Kana Word Puzzle in Online Learning is a crossword you play by dragging kana.

Easy-going rules

  • Each kana once. The kana in a set are all different, and each one can be used once in a word.
  • Small kana can also be used. ゃ, ゅ, ょ, っ and the other small kana, and the long-vowel mark ー, can also be used to create words. For example, しゅくだい only needs し, く, だ and い.
  • Dakuon can also be used. The kana in a set are plain, with no dakuon. If the set has か, you can also use が. If it has は, you can also use ば or ぱ. For example, with た, ま and こ in the set you can make たまご.
  • Katakana is fine. A kana can be written in hiragana or in katakana, so ケーキ only needs け and き. The answer key lists words like these too.

Frequently asked questions

Is there an answer key?

Yes. With "Include an answer key page" on, the PDF ends with a key page. For each puzzle it lists the words from the word list that the kana can make, with their points. Students may find other real words, and those count too.

Does it include katakana?

Not yet. The word list is hiragana only, so the kana are hiragana.

Do I have to type in words?

No. The kana are made for you from the built-in word list. Press Shuffle to get a new set.
