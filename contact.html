What helps us fix a problem quickly

  • Which tool you were using (Math, Kana Quiz, or Writing Practice).
  • The worksheet code printed at the top of the page, such as XRGD0831-A-1.
  • For a wrong answer, the problem number and the answer you expected.
  • For display or printing problems, your browser and device (for example, "Safari on iPad").
  • If you use the Export (.ini) button, attach the settings file so we can reproduce the exact sheet.

Please don't include a child's full name or other personal details. The issue tracker is public.
